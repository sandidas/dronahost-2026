# How to check your WordPress version

You can check which WordPress version your site runs from the dashboard, the Updates screen or the page source. The dashboard shows it at the bottom of every admin page and on the Updates screen. Knowing your version tells you whether security fixes are waiting, and whether your plugins support the version you run.

## Find it in the dashboard

Log in and open the Updates screen. The version number sits at the top of the page. See our [WordPress hosting page](/wordpress-hosting) if you want help running updates, or [contact the team](/contact).

## Find it from the page source

Open the site, view the source and search for the generator tag. Compare plans on the [pricing page](/pricing) if you are thinking about a change of host.

## FAQ

### Where is the WordPress version shown in the dashboard?

Log in and look at the bottom right of any admin page. The version number is printed there. You can also open Dashboard, then Updates, which shows the version you run and whether a newer one is available. Both places read the same number, so use whichever is faster for you.

### Can I see the version without logging in?

Often yes. Open the site, view the page source and search for the word generator in the head. Many themes print the version there. Some sites hide it on purpose, so a missing tag does not mean the site is out of date. If you own the site, the dashboard is the reliable place.

### Why does my WordPress version matter?

Each release fixes bugs and closes security holes. An old version can miss those fixes, and some plugins stop supporting it. Check the version before you add a plugin or change your PHP version, so you know what you are working with and what to update first.

### Should I update WordPress straight away?

Take a backup first, then update. If you can, try the update on a staging copy and check your key pages. Small security releases are usually safe to apply quickly. Larger releases can change how a theme or plugin behaves, so give yourself time to test them.
