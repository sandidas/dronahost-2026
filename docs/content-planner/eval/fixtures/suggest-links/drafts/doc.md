# Blog launch checklist

Before you launch, pick managed blog hosting that fits your traffic. Test a site backup guide and restore site backup files once. See [blog hosting plans](/blog-hosting) for options. Add blog caching to keep pages quick, and read how to speed up a blog next. Ignore the banned topic page.
